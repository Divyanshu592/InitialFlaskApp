# 🚨 SentinelGuard: Anomaly Detection System

## 📌 Overview

**SentinelGuard** is an intelligent anomaly detection system designed to identify unusual patterns and suspicious activities in data. The system uses advanced deep learning techniques to detect anomalies in time-series and sequential data.

It helps in monitoring systems, detecting security threats, and identifying abnormal behavior in real-time.

---

## 🧠 Technologies Used

This project uses the following deep learning models:

* ✅ **LSTM (Long Short-Term Memory)**
* ✅ **GRU (Gated Recurrent Unit)**

Both models are implemented to improve accuracy and reliability in detecting anomalies.

---

## ⚙️ Features

* 📊 Real-time anomaly detection
* 🔍 Deep learning-based prediction
* 🚀 Web-based interface using Streamlit

## 📊 Model Description

### 🔹 LSTM Model

LSTM is used to capture long-term dependencies in sequential data, making it suitable for detecting complex patterns.

### 🔹 GRU Model

GRU is a lightweight alternative to LSTM with faster training time and comparable performance.

Both models are evaluated to ensure better anomaly detection.
